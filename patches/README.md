# Patch

`skyward-waffle.patch` is the diff from upstream `kirklin/skyward` 0.3.1 to
the tree in `../skyward`. Apply it with `git apply -p1` at the root of a
fresh upstream checkout.

It contains the OnePlus compatibility work from
`shawude/skyward-oneplus13-sun`, the shared port fixes, and the single
`devices/waffle.toml` for the OnePlus 12.
